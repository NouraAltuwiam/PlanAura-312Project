# PlanAura 

PlanAura is an event planning web platform that connects customers with 
service providers (venues, catering, and decoration/theme companies) to 
plan and manage events like weddings, graduations, and birthday parties.

🔗 **Live Demo:** https://planaura.netlify.app

## Features
- Browse and filter services (Venues, Food & Beverages, Decorations & Themes) 
  with sorting by price and name
- Customer Dashboard for tracking bookings and requests
- Provider Dashboard for managing offered services
- Service request & evaluation flow between customers and providers
- Partner showcase page and customer reviews section
- User profiles and team management page
- Responsive design with a Dark Mode toggle

## Tech Stack
- HTML5
- CSS3 (custom, no framework)
- JavaScript (Vanilla)
- Netlify (deployment)
